読み込み中…

e-Stat のファイルを読み込む

  1. e-Stat 住宅着工統計 月次（Excel）、またはデータベースで表を開く。例：「【住宅】利用関係別 構造別 建て方別 都道府県別 戸数」、「15 都道府県別、工事別、利用関係別／戸数・件数、床面積」
  2. 表示項目で必要な年月・地域・区分を選び、「ダウンロード」から CSV（列指向形式） を保存
  3. ここに読み込む。複数ファイルはまとめて結合されます
CSV・Excel（.csv / .xlsx / .xls）をここにドロップ

2025年以降の月次はExcelでのみ公開されています。e-Statの「住宅着工統計 月次」から各月の「表15 都道府県別、工事別、利用関係別」などのExcelを保存し、まとめて選んでください。年月はファイル名か表の見出しから読み取ります。

列指向（1行1数値）と、年月を列に並べた横持ちの表にも対応します。地域名・年月（「2025年8月」「2025年」「2025年度」「令和7年8月」など）・区分列を自動判別します。

e-Stat API から取得する

e-Stat の利用登録で発行されるアプリケーションIDが必要です。この公開ページからは外部APIに接続できません。同じHTMLをGitHub Pagesなどのウェブ上に置いて開くと使えます（iPhoneのSafariでも可）。

取得方法

検索で見つかった統計表を選んで取得します。月ごとに分かれた表はまとめて結合します。前年同期比のため、開始年の前年分から取得します。

e-Statのデータベース（API）は年1回の更新で、月次は2024年12月分までです。2025年以降は「月次Excelをダウンロード」で取得し、「今のデータに追加する」でつなげてください。取得は全国と47都道府県に絞り、ゼロの値は保存しません。

月次Excelをダウンロード

2025年以降の月次はExcelのみの公開です。e-Statのデータカタログから各月のExcelを探してボタンにします（アプリケーションIDを使います）。

ボタンを押すとExcelが保存されます（iPhoneは「ファイル」アプリの「ダウンロード」）。保存後、左の「ファイルを選ぶ」でまとめて選んでください。
