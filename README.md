# 住宅着工 景況マップ

国土交通省「建築着工統計調査（住宅着工統計）」を、年・月・都道府県別に前年同期比で集計し、表と都道府県色分け地図で表示するアプリです。

- 公開URL: https://heqiguangda-coder.github.io/housing-starts-map/
- データ: e-Stat API（アプリケーションIDが必要）または e-Stat からダウンロードした CSV／Excel
- 初期表示は操作確認用の架空データです
- アプリケーションIDはブラウザ内にのみ保存され、このリポジトリには含まれません
- 地図: [dataofjapan/land](https://github.com/dataofjapan/land) の都道府県境界を簡略化して使用
